# Channel Integrity: how Convoke arrives

> **Status: draft — Discovery in progress.** Nothing below is a requirement yet.
> The trigger and the measured position are recorded first because they are derived
> facts, not proposals: every figure was produced by execution on 2026-09-26, and
> mechanism claims carry their primary source in `addendum.md`.

## Trigger

A `skills.sh` page listed one Convoke agent — `bmad-bme-agent-wade`, one install —
though nothing had ever been published to that registry.

**It was not a crawl, and it was not luck. Convoke's own manifest declared him.**
The CLI walks a fixed list of container directories three levels deep, but
manifest-declared paths bypass that walk entirely, and
`.claude-plugin/marketplace.json` declares
`./_bmad/bme/_vortex/agents/lean-experiments-specialist` — five levels deep, outside
every container directory. The manifest *is* Convoke's discovery surface.

Which settles a question nobody had asked: **Convoke already publishes to a public
channel, deliberately, and it publishes 7 of its 11 agents and none of its
workflows or contracts.** The listing did not create the exposure. It rendered it.

`convoke-install-gyre` at install time. The public discovery surface of the
repository is **nine** skills: two tracked under `.claude/skills/` plus the seven the
manifest declares.
