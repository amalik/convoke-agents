# Credits

Convoke is built by agents, and it seemed wrong not to say so. Two groups are named below: the agents Convoke ships, and the agents that built it. Every one of the latter contributed to the design, implementation, testing or documentation of this project.

## Foundations

- [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) — the agent architecture Convoke is built in
- [Innovation Vortex](https://unfix.com/innovation-vortex) — the seven-stream discovery pattern behind the Vortex team, from the [unFIX model](https://unfix.com/) by [Jurgen Appelo](https://jurgenappelo.com/)
- Claude (Anthropic) — reasoning and agent development
