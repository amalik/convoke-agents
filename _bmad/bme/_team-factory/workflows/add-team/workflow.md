# Add Team Workflow

Creates a new BMAD-compliant team module under `_bmad/bme/` — agents, workflows, config, and the
registry/manifest wiring that makes it discoverable — through five guided steps.

The architectural thinking happens **before** any file is generated. Steps 01-03 produce and
approve a spec; only step 04 writes anything.

## Entry

Reached from [`../step-00-route.md`](../step-00-route.md), which classifies contributor intent and
routes "create a new team" here. Step 00 also supports two shortcuts that change where you enter:

| Invocation | Behaviour |
|---|---|
| no data | Full run from step 01 |
| `data="resume"` | Load the existing spec, diff it, and jump to the first incomplete step |
| `data="express"` | Load a prepared spec and jump straight to step 03 (review as full validation gate) |

## Pipeline

| Step | File | Produces |
|---|---|---|
| 01 | [`step-01-scope.md`](step-01-scope.md) | Team composition pattern, agent inventory, roles |
| 02 | [`step-02-connect.md`](step-02-connect.md) | Contracts, output directory, compass routing, config fields |
| 03 | [`step-03-review.md`](step-03-review.md) | Approved decision summary — the gate before generation |
| 04 | [`step-04-generate.md`](step-04-generate.md) | Generated files + integration wiring |
| 05 | [`step-05-validate.md`](step-05-validate.md) | End-to-end verification, file manifest, run metrics |

Content artifacts are generated by delegating to BMB; integration wiring is performed by the
factory's own JS utilities under [`../../lib/`](../../lib/).

## Prerequisites

- The `team-factory` agent is installed (`_bmad/bme/_team-factory/agents/team-factory.md`)
- A writable output folder — `output_folder` in [`../../config.yaml`](../../config.yaml)

## Safety

Step 04 is the only step that writes to the repository, and every write goes through the factory's
writer layer, which refuses to overwrite a file carrying uncommitted changes. Team Factory is
supported in projects that are not git repositories; in that case the dirty-tree check has nothing
to compare against and writes proceed. See `lib/writers/registry-writer.js`.
